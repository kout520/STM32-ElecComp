# 无刷电机驱动（六步换相 + 霍尔传感器）

基于 STM32F1 HAL 库的三相无刷直流电机（BLDC）六步换相驱动，配合霍尔传感器实现换相。

> 适用场景：电赛里直接驱动三相无刷电机（需外接三相 MOSFET 驱动板，如 DRV8301 / EG2133 + MOS / IR2104 方案）。
> 若你是用成品电调（ESC），请用「50Hz PWM 油门」方式，不要用本模块。

## 一、文件说明

| 文件 | 说明 |
| :--- | :--- |
| `bldc.h` | 头文件，包含所有配置宏与函数声明 |
| `bldc.c` | 驱动实现（六步换相表 + 定时器换相逻辑） |

## 二、硬件连接

### 1. 三相驱动板（6 路栅极输入）

| STM32 (TIM1) | 驱动板 | 说明 |
| :--- | :--- | :--- |
| CH1  (PA8)  | UH | U 相上桥臂 |
| CH1N (PB13) | UL | U 相下桥臂 |
| CH2  (PA9)  | VH | V 相上桥臂 |
| CH2N (PB14) | VL | V 相下桥臂 |
| CH3  (PA10) | WH | W 相上桥臂 |
| CH3N (PB15) | WL | W 相下桥臂 |

> 引脚以 TIM1 完整重映射（`TIM1_FULL_REMAP`）为例；具体按你的 CubeMX 分配为准。

### 2. 霍尔传感器（3 路）

| STM32 | 霍尔 | 说明 |
| :--- | :--- | :--- |
| PB5 | HA | 霍尔 A |
| PB6 | HB | 霍尔 B |
| PB7 | HC | 霍尔 C |

> 默认引脚在 `bldc.h` 配置区可改。霍尔模块通常需接 5V（或 3.3V）与 GND。

## 三、CubeMX 配置要点

1. **TIM1（高级定时器）**
   - Clock Source：Internal Clock
   - 三个通道 CH1/CH2/CH3：`PWM Generation CHx`
   - 打开互补输出：`CHxN`（CH1N/CH2N/CH3N）
   - 计数：向上计数（边沿对齐），`Prescaler`/`Counter Period` 按所需频率设置
   - `Break and DeadTime`：死区时间建议 0.5us ~ 2us（防止上下桥直通）
   - PWM 频率建议 10kHz ~ 20kHz
2. **霍尔 GPIO（PB5/PB6/PB7）**
   - 若走中断换相：GPIO mode 选 `External Interrupt Mode with Rising/Falling edge`
   - NVIC 使能对应 EXTI 中断（PB5/6/7 → `EXTI9_5_IRQn`）
   - 若走轮询换相：配成普通输入即可（推荐外部中断，换相更及时）

## 四、移植步骤

1. 把 `bldc.c`、`bldc.h` 拷进工程（如 `Core/Src`、`Core/Inc`），加入编译。
2. 若你的芯片不是 F1，改 `bldc.h` 顶部的 `#include "stm32f1xx_hal.h"` 为对应系列。
3. 在 `main.c` 中包含 `#include "bldc.h"`。
4. 按需修改 `bldc.h` 配置区：定时器句柄、通道、霍尔引脚、极对数。

## 五、使用示例（main.c）

```c
#include "bldc.h"

int main(void)
{
    HAL_Init();
    SystemClock_Config();
    MX_GPIO_Init();
    MX_TIM1_Init();      // CubeMX 生成的 TIM1 初始化

    BLDC_Init();                              // 初始化
    // BLDC_Hall_Init();                      // 若未在 CubeMX 配霍尔 EXTI，则用代码初始化
    BLDC_Set_Direction(BLDC_DIR_FORWARD);     // 正转
    BLDC_Set_Speed(30.0f);                    // 30% 占空比起转
    BLDC_Start();                             // 使能输出

    while (1)
    {
        // 若走轮询换相（未用 EXTI），在这里高频调用：
        // BLDC_Commutation();
    }
}
```

### 中断换相（推荐）

在 `stm32f1xx_it.c` 或任意处重写 HAL 回调：

```c
void HAL_GPIO_EXTI_Callback(uint16_t GPIO_Pin)
{
    if ((GPIO_Pin & (HALL_A_PIN | HALL_B_PIN | HALL_C_PIN)) != 0)
    {
        BLDC_Commutation();
    }
}
```

### 测速

每隔固定时间（如 50ms）调用一次：

```c
float rpm = BLDC_Get_RPM(0.05f);   // 返回机械转速 RPM
```

## 六、API 速查

| 函数 | 作用 |
| :--- | :--- |
| `BLDC_Init()` | 初始化定时器/PWM，进入安全状态 |
| `BLDC_Hall_Init()` | 可选，用代码初始化霍尔 EXTI |
| `BLDC_Start()` / `BLDC_Stop()` | 使能/关闭输出 |
| `BLDC_Set_Duty(uint16_t)` | 设占空比（CCR 值 0~ARR） |
| `BLDC_Set_Speed(float)` | 设占空比（0~100%） |
| `BLDC_Set_Direction(BLDC_Direction)` | 设正转/反转 |
| `BLDC_Commutation()` | 换相（EXTI 或轮询调用） |
| `BLDC_Read_Hall()` | 读霍尔三位编码 |
| `BLDC_Get_RPM(float)` | 测速，返回 RPM |
| `BLDC_Get_Hall_Count()` | 霍尔变化累计次数 |

## 七、排错

- **不转 / 抖动 / 电流大**：先确认占空比别给太大（从 10%~20% 起），检查霍尔是否接对、供电是否正常；尝试**交换任意两根电机相线**，或**交换任意两路霍尔线**后重试。
- **转向反了**：交换任意两根电机相线，或调用 `BLDC_Set_Direction(BLDC_DIR_REVERSE)`。
- **电机只在某个位置抖**：多为霍尔信号缺失/接错，检查三路霍尔是否都有高低变化。
- **上下桥直通（发热烧管）**：确认已配置死区时间，且 `BLDC_Init()` 后先给速度再 `BLDC_Start()`。

> 不同厂家电机/驱动板的相序与霍尔相位并不统一，换相表以 `bldc.c` 顶部注释为准，必要时按实际相序调整。
